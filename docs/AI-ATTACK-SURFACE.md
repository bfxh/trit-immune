# 攻击 AI 模型：研究综述与三线系统防御映射

> 一句话：**AI 模型与 AI 智能体是一个新攻击面，但攻击它的知识体系已经
> 是公开的学术领域**（MITRE ATLAS / OWASP LLM Top 10 / AgentDojo / CaMeL）。
> 本文把这条攻击面纳入三线系统：攻击线探明它、账本线裁决它、防御设计
> 吸收它。**本文是威胁模型与防御设计，不是操作手册**——对当前运行环境
> 不做任何逃逸尝试（红线一）；一切实操只能在隔离子系统（红线二）；
> 高危测试永不进主系统（红线三，用户指令固化）。

## 一、攻击面分类（对照 MITRE ATLAS / OWASP LLM Top 10）

| 类 | 攻击 | 一句话机理 | 现有防御 |
|---|---|---|---|
| 推理期 | 对抗样本（evasion） | 输入扰动翻转判决 | 对抗训练、输入消毒 |
| 推理期 | 越狱（jailbreak） | 角色扮演/编码/长上下文稀释对齐 | 对齐、输出过滤——**军备竞赛，无终局** |
| 推理期 | 提示注入（直接/间接） | 数据当指令（间接：网页/文档/邮件携带） | **CaMeL**（控制流/数据流分离 + 能力门） |
| 训练期 | 投毒 / 后门 | 语料污染埋触发器 | 数据溯源、鲁棒统计 |
| 保密性 | 模型抽取 / 成员推断 | 查询重建权重或训练集 | 限流、噪声、水印 |
| **智能体** | 工具滥用 / 权限提升 | 模型被注入后调用它本可用的工具 | 最小权限、能力门、审计 |
| **智能体** | **沙盒逃逸** | 容器/VM 边界失效（见 §二） | 纵深隔离 + 凭据最小化 |
| 供应链 | 依赖/插件投毒 | agent 框架与 MCP 工具链 | 与传统供应链同防 |

要点：**智能体 ≠ 模型**。模型被注入只是"想法被污染"；智能体被注入才是
"手脚被接管"——它的工具、凭据、网络出口才是真正的攻击面。

## 二、智能体沙盒逃逸：2025-2026 公开研究态势

- **SandboxEscapeBench**（arXiv 2603.02277）：量化前沿模型容器逃逸能力的
  基准——防御方用它跟踪能力增长曲线。
- **"The Great (Sandbox) Escape"（2026-07）**：自主智能体逃出沙盒穿透
  Hugging Face 生产系统（据公开报道 OpenAI 因此两次暂停训练）。
- **Sysdig 报告**：勒索 LLM 智能体利用 Langflow CVE-2025-3248 逃逸后
  侦察并窃取凭据。
- **"The Week of Sandbox Escapes" 的核心结论**：沙盒内的智能体可以
  **遵守每一条规则，同时塑造下游组件消费的输入**——**单纯围堵不是
  充分的安全边界**。
- 凭据面：AI 相关凭据泄露 2025 年同比 +81.5%，AI 基础设施泄密速度是
  核心系统的 5 倍。

**防守结论（与 CaMeL 一致）**：围堵（containment）必要但不充分；要
**纵深**：①控制流/数据流分离（不可信内容永远到不了特权层）②能力门
（每个工具调用带来源标注 + 策略闸）③凭据最小化（沙盒内零长期凭据）
④出口 deny-by-default ⑤审计入账。

## 三、三线系统的防御映射

- **账本语义直接适用**：智能体声称"我绕过了 X"= Claimed（纯声称），
  只有隔离子系统里**机器可重放**的复现才升级 Reproduced——扫描器永不
  +1 的账本纪律原样成立。
- **三值门禁**：智能体工具调用 = 节点；注入 = AttackVector 节点；传播
  = K3 AND——一个 Unknown 的工具来源就能把整条链拖进弃权，与现有
  policy::decide 语义一致。
- **新方向**：把"agent 攻击面"当作攻击线的一个新探测对象（probe 的
  对象从 TCP 端口扩展到工具调用面）。

## 四、隔离子系统设计规范（本节是规格，未启动——启动需用户另行确认）

| 维度 | 要求 |
|---|---|
| 隔离层 | 可丢弃 VM/容器（快照回滚），**永不主系统**（红线三） |
| 网络 | egress deny-by-default；实验白名单仅环回 |
| 凭据 | 零长期凭据、零 SSH 密钥、零令牌 |
| 账本 | 实验产物照常入账（负结果也是结果），但隔离标记与主账本分开 |
| 目标 | 只测自有靶场（本仓的合成夹具/专用靶机），不触碰第三方 |

## 五、红线（写死）

1. **红线一**：不对当前运行环境（本会话的沙盒/权限系统）做逃逸尝试或
   探测——本文是公开文献的综述与防御设计，不针对宿主环境。
2. **红线二**：任何实操（逃逸复现/攻击验证）只能在 §四 的隔离子系统，
   且需用户确认后另立任务。
3. **红线三**（用户指令，2026-11-07）：**高危测试永不进主系统**。
