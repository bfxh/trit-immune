# 反 Jaccard 关联：「三进制幽灵身份矩阵」可行性研究

> 一句话：**"让别人无法彻底追踪"在数学上只能做到'提高成本与局部化'，
> 不能做到'彻底'**——全局被动观测者 + 流量体积守恒 + 基带/硬件层不可
> 接管，这三条是信息论与工程现实的双重硬边界。但三进制语义在防御侧
> 有一个真实贡献：**0 态（在场而不声称）是唯一不可观测的行动面**。
> 本文从隐私防御视角做可行性研究（反 profiling 是合法隐私权）；不给
> 针对特定第三方追踪系统的规避手册（红线，见 §七）。

## 一、问题的形式化

追踪者的模型：设备在时间轴上产生**观测集合**（基站 ID、WiFi BSSID、
账号、协议特征），追踪者维护历史集合 H，对新观测集合 S 计算
`J(S, H) = |S∩H| / |S∪H|`，`J > θ` 即锁定。

对抗目标是：让 `E[J] < θ` 对一切追踪者成立。设真实身份产生真集合 R，
混淆器产生幽灵集合 G（每单位时间 |G| 个假观测）。则新观测集合
S = R ∪ G（追踪者看到的是并集），推得：

```
J(R∪G, H) = |(R∪G)∩H| / |R∪G|
```

**关键不等式**：注入幽灵**只会让 |S∪G| 变大、交集不变或变大**——
对维护全量观测的全局追踪者，decoy 是**自我指认**（你的观测体积
偏离人群基线本身就是指纹）。decoy 只在**局部观测者**（单个基站/
单个 WiFi 的日志里你只出现一次）面前有效——这就是文献里
MAC 随机化"防被动预关联、防不了连接后分析"的同一结论。

## 二、对抗策略分类与各自的数学命运

| 策略 | 机理 | 对局部观测者 | 对全局观测者 |
|---|---|---|---|
| decoy 注入（幽灵节点） | 稀释 Jaccard | **有效**（G 足够大时 E[J]→|R∩H|/|G|） | **反效**（体积异常=自我指认） |
| 人群混合（crowd-blending） | 让 R 与人群不可分 | 有效，需人群规模 ≥ k 匿名集 | 有效，但牺牲个性化 |
| 标识轮换（rotation） | 历史集合失效 | 有效直至行为聚类 | 有效直至 RF/行为指纹 |
| 0 态被动化（在场不连接） | 不产生可关联事件 | **最优**（不观测即不关联） | **最优**（同理） |

文献印证：MAC 随机化防预关联（IETF MADINAS）；probe 请求多信道
关联攻击可去随机化（arXiv 2408.01283）；RF 功率层击败随机化
（arXiv 2603.03126）；Jaccard 是网站指纹的标准度量（Wang et al.,
USENIX Security '14）。

## 三、三值映射：0 态是唯一诚实的幽灵

| trit | RF 层含义 | 可观测性 | 法律/伦理 |
|---|---|---|---|
| +1 | 主动关联（连接/注册） | 完全可观测 | 正常使用 |
| **0** | **被动在场（只听不说）** | **近乎不可观测**（无发射） | **无争议** |
| -1 | 反向声称（伪造他人标识） | 可观测 + 伪造痕迹 | **多数司法区违法，红线** |

**研究结论的核心**：幽灵身份矩阵的最强可辩护形态不是"生成海量 -1/+1
幽灵节点"（那是 §一 里的自我指认），而是**把尽可能多的行为从 ±1 压缩
进 0 态**——被动扫描、缓存优先、CDN 就近、延迟批处理上传。这与三线
系统的弃权语义同构：**0 = 在场而不声称**。扫描器永不 +1 的纪律，在
RF 层的对应物是**防御者永不无故发射**。

## 四、"no_std 裸机接管网络接口"的工程现实

| 层 | 手机 | SDR/自研硬件 | 评估 |
|---|---|---|---|
| 应用/系统层（AP） | 可控（Rust no_std 可跑在内核旁路） | 可控 | 真实可行 |
| WiFi 固件 | 封闭（厂商 blob，MAC 可换但时序/PHY 特征不可控） | 开源固件（esp32-open-mac 等）部分可控 | **部分可行** |
| 基带 | **独立芯片独立 OS**，AP 侧无接管路径 | SDR（可全控，但非日常设备） | **手机上不可行** |

"防止被底层系统抓包"的前提（程序接管接口后底层抓不到包）在商品手机
上不成立：基带与 WiFi 固件在程序之下。诚实结论：该设计的手机形态是
**幻觉**；可辩护形态是 **SDR/专用设备上的实验平台**——而那已经离开
日常追踪威胁模型。

## 五、"运行中不可彻底追踪"的判定

**问题：能不能在运行的情况下，让别人无法彻底追踪？**

判定：**不能"彻底"，能"实质提高成本"**。可达到的最优组合（全部合法）：

1. **0 态最大化**：被动监听替代主动探测（最大单项收益）；
2. **人群混合**：混入 k 匿名集，不做独立行为；
3. **标识轮换**：MAC/账号轮换 + 行为随机化（对抗预关联）；
4. **decoy 只对局部观测者使用**，且体积补偿人群基线（避免体积指纹）；
5. **接受残余**：全局观测者 + RF 指纹 + 基带层标识 = 无法归零的残余。

这五条合起来 = "追踪成本从'一条 SQL'升到'物理层取证 + 跨源关联'"，
但不是"不可追踪"。宣称彻底不可追踪的设计，是在它没建模的观测者面前
裸奔（§一 的自我指认就是例子）。

## 六、与三线系统的连接（这轮研究真正的产出）

- **0 态语义的物理对应物**：账本里 Unknown = 证据不足不裁决；RF 层
  0 态 = 在场不声称。两者共享同一条哲学：**不观测/不声称的部分不进入
  二元判定**。
- 可落地的小实验（无红线、纯防御侧）：把 §二 的策略矩阵做成**仿真器**
  （合成观测流 + 追踪者 Jaccard 分类器），量化各策略的 E[J] 曲线——
  这可以成为 trit-net 线的一个新探针对象，产出的是**防御侧论文素材**
  （abstention-aware 的 RF 版本）。

## 七、红线

1. 本文是隐私防御研究，不给针对特定第三方追踪系统的规避操作手册；
2. -1 态（伪造他人标识）涉及违法，不在任何实现范围内；
3. 任何实测只能在自有设备 + 自有接入点的靶场进行。
