# 论文骨架：弃权是一等输出（Abstention as a First-Class Output）

> 一句话：**安全检测的二元输出藏着一个被系统性隐藏的第三态——证据不足**；
> 现有工具把弃权折叠成"良性"（fail-open）或"报警"（狼来了），两者都不可
> 复算。本文主张弃权是**可复算的输出**：三值裁决账本让弃权可传播、可门禁、
> 可发布、可审计。骨架已立（2026-11-07），实证材料全部落库可复算——缺的
> 只有 N1 校准级批次的人工误报/漏报率一个数字。

## 一、论点（thesis）

静态安全检测系统（扫描器、规则引擎、逆向分析）输出的"恶意/良性"是一个
**藏在二元界面后的三值事实**。第三态（Unknown / 弃权）产生于：输入截断、
预算耗尽、子集边界、不可静态求值的构造、以及"没看见 ≠ 不存在"。主流工具
把第三态**静默折叠**进二元——折叠成良性是 fail-open（漏报），折叠成报警
是狼来了（误报疲劳）。本文给出一个把弃权当作一等输出的完整系统：

1. **语义层**：Kleene 三值（T/F/U）贯穿扫描、规则求值、账本、门禁；
   U 在任何一层都不塌缩（Kleene AND/OR：F 与 T 支配，U 沾边即弃权）。
2. **纪律层**：**扫描器永不 +1**——静态 False 不是安全证明（动态解析/
   混淆/未知向量都在 False 的盲区里），账本只收 T（能力确认）与 U；
   False 作为"未看见"如实丢弃并计数。
3. **账本层**：追加式日志 + δ-CRDT 合并（Almeida et al. 的 delta-StateCRDT
   语义在安全域的落地），修正不删除、来源可溯源（`scanner:<sha256>` 前缀）。
4. **发布层**：对外主张不许比证据更乐观——`affected` 只给机器可重放的
   复现证据，纯声称降级 `under_investigation`（VEX/CSAF 的证据分级）。

## 二、贡献（contributions）

- **C1 三值检测管线的完整落地**：感知（逆向/流量）→ 裁决（账本）→ 执行
  （门禁/排活）三层，每层只与相邻层说话；跨层数据的翻译与消毒（桥）是
  任务密集区。
- **C2 弃权的机器可判定来源清单**：每一类弃权都有确定性的复算命令——
  输入截断（调用方声明）、预算耗尽（`SCAN_BUDGET` 1M 步/模式，确定性
  封顶不挂起）、记名弃权（`entrypoint`/模块引用带名字进 AST）、子集边界
  （四态对拍的 `SUBSET-GAP` 类）。**弃权不是"我们不知道"，是"我们知道
  为什么不知道"**。
- **C3 扫描器永不 +1**：修正与声称的账本分离；修复后复现历史不消失
  （修正不删除）；verified_ratio 只统计可重放证据（openai/math 的
  "42% formalized" 对应物）。
- **C4 分层证据发布**：VEX 状态从账本证据层级派生而非人工填写；
  attestation 双 subject（账本摘要 + 发现目录摘要）可独立核对。
- **C5 实证**：官方引擎对拍（四态分类，语义分歧实测判定法）+ 12 个真实
  系统二进制的活体弃权案例研究 + 两个负结果（拒绝给死代码找主、拒绝
  调宽基线换绿灯）。

## 六、威胁与诚实边界（论文必须自报的）

1. 单一实现（trit 系）——语义层的通用性靠"每类弃权的复算命令"支撑，
   不主张统计外推。
2. E4 人工复核样本未到位——误报/漏报率缺位是当前最大威胁；骨架已把
   复算协议写死，数字一到即填。
3. 子集边界（正则/pe.* 模块）——弃权处理了它们，但覆盖面主张必须带
   SUBSET-GAP 口径。
4. 演练批次是系统库（干净域）——攻防样本批次（恶意域）未进，-1 侧的
   传播/门禁叙事目前靠真注入样本的单点实证（#51 演练）。
