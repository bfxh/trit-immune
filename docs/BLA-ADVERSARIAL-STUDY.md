# BLA 对抗研究：怎么把破解 AI 逆向防御盾的成本压到 10×

> 2026-11-13。对象：morluto/rea（给编码 agent 的逆向工具集，MCP + CLI，
> 覆盖原生二进制/JS/Electron/.NET/APK/WASM/模型工件等 30+ 目标，证据返回式）
> 与 qybaihe/bla（针对 REA 类 agent 的防御盾：**毒饵→耗尽→纠缠→楚门世界**，
> 宣称 300×–2800× token 放大、14/14 运行时等价）。立场：**防御研究**——BLA
> 自带公开 CrackMe 竞技场（v6–v9）明确邀请红队方法验证；本文不针对任何

## 一、威胁模型：这两样东西到底在对抗什么

- REA 把"逆向"从手艺变成**对话**：agent 问一句，REA 出伪代码/证据/未知项。
  说明书口径：未防护工件上克隆核心逻辑"几秒、约 $0.20"。
- BLA 的赌注是三件事：①agent 的上下文有限且贵（毒饵与耗尽都打这个）；
  ②agent 信任工具返回的结构合法性（毒饵全格式合法）；③agent 爱走捷径
  （单点 patch、把导出当 oracle——纠缠打这个）。
- 关键事实：BLA 的耗尽全靠 **REA 的实现常数**（`MAX_BUILD_INFO_BYTES`
  1 MiB、ASAR 头 16 MiB、Wabt 表示预算、tshark JSON 8 MiB、
  `primitive-candidates > 256`、模型元数据嵌套 32 层……）——这些阈值
  **写在 REA 的开源代码与 BLA 自己的 README 表格里**。

## 二、打破路径：探针 → 地图 → 换通道 → 动态锚定 → 精读（成本 ≈ 10×）

把 BLA 宣称的 2800× 压到 10× 的最小方法论，五步、每步一次性成本：

### 2.1 预算探针先行（≈1×）——错误消息是免费的配置泄露

不用完整分析 pass 去踩 19+ 颗雷。对每个格式发**最小调用**，REA 返回的
`CapacityError` / `LIMITED` + 预算名（"ASAR header exceeds 16 MiB"、
"primitive-candidates exceeds 256"）就是 BLA 的**防御配置自白**：阈值、
格式、触发条件全在里面。一次探针 pass 建立全格式地雷图，成本 O(格式数)
与样本大小无关。**毒饵与陷阱的排布本身就是情报**——它标记了作者认为
值得保护的位置。

### 2.2 换通道（≈1×）——防的是通道不是内容

BLA 的耗尽全部作用在 **REA 内置解析器的预算壳**上：ASAR 头 16 MiB 挡的
是 REA 的 reader，不是 ASAR 格式。直接调格式原生工具
（`asar extract`、`wasm2wat`、`sqlite3` CLI、Python `marshal`、自写
zstd/tar 解包）绕开包装层——预算常数对一个**不经过 REA 的分析者**不
存在。**推论：实现常数的预算防线，对换通道者失效**（见 §四 定理 2）。

### 2.3 语义惰性检测（≈1×）——毒饵的统一签名

毒饵千姿百态（opaque predicate、蜂蜜 SourceMap、影子状态机、蜜表、
SGX/TPM 假清单），但有一个**统一的结构签名**：

> **格式合法但语义惰性——生产的字节没有任何真实消费路径。**

三个可机判的子签名：
1. **不可达谓词**：数论 opaque predicate（`7x²−1 ≠ y² (mod 7)`）是
   **恒真式**——小规模枚举/符号求值直接判死，成本 O(1)；
2. **零消费者**：从数据/导出点反向追踪读取路径——无消费者的表、映射、
   状态机 = 假数据（BLA 的蜜表按构造没有真实读写路径）；
3. **与动态观测冲突**：跑一次真实输入（用户态——BLA 自认"normal user
   execution untouched"，**楚门只对检测到的调试器撒谎**），录 I/O 与
   状态迁移；静态毒饵与观测行为冲突即标记丢弃。

### 2.4 动态锚定（≈2×）——一锤定音的便宜证据

静态 vs 静态永远打嘴仗（BLA 的毒饵就是为嘴仗设计的）；**行为事实**只
有一条。strace/API hook/抓包一轮，把"程序实际做了什么"锚定下来，之后
所有静态阅读以行为为准绳——毒饵免疫的本质是**给证据分级**：复现 > 静态
声称（这正是 trit-immune catalog 的 `Reproduced > Adjudicated > Claimed`
层级）。

### 2.5 聚焦精读（≈6×）——只在真核上花深度预算

地图 + 通道 + 锚定之后，剩余的真实逻辑面 ≈ 原始未防护面。对它做一次
正常深度分析。合计 ≈ 10×——**BLA 的 2800× 放大率对无地图的蛮干 agent
成立，对带方法论的分析者是常数因子**。

### 2.6 纠缠（Entangle）为什么防得住也防不住

SHA-256 sibling 绑定让"单点 patch / 删毒饵"失效——**防篡改是真防御**
（改一处要重签全家）。但分析者不需要篡改，只需要**理解**；即便要改，
重 seal 的成本 = 按同一清单算一遍哈希（BLA 自己定义了清单结构）。
**防篡改 ≠ 防理解**——这是 BLA 唯一的硬防御，也是最便宜可被复用的。

## 三、楚门世界的裂缝

"Runtime Truman Show"（检测 CDP/Frida/Inspector 后给假遥测）依赖
**检测器**——检测器本身是可探测的代码：
- 它必须区分"用户正常跑"与"调试附加"→ 两者的系统调用/时序/句柄差异
  存在，反向检测检测器（对着差异面 fuzz）是标准手法；
- 假遥测要"可信"就必须与真实实现共享大部分状态 → 真假混合态本身就是
  可检测的不变量（假遥测永远不会导致真实的副作用——副作用差分即真相）。
成本不低（这是 BLA 最硬的一层），但注意它**只保护 Electron 运行时**
一种形态，覆盖面最窄。

## 四、理论化：两条定理 + 一个二分

### 定理 1（毒饵免疫，非形式）

*任何"格式合法但语义惰性"的投毒，在【多源交叉验证 + 动态锚定】下，
识别成本 = O(投毒量)，与被保护程序的分析总量无关；且被识别的毒饵是
高价值情报（标出防御者的保护意图）。*

- 论证：惰性 = 无真实消费路径/与行为观测冲突（§2.3 三签名可机判）；
  交叉验证把"每个毒饵"从"分析成本"变成"一次冲突判定"；冲突判定本身
  产出关于防御者意图的信息。**推论：Poison 支柱对带交叉验证的分析者
  是负资产**——毒越多，地图越好画。
- 这是 trit-immune 模因抗性框架（MEMETIC-RESISTANCE）的攻防镜像：
  TMR 多源表决（单源毒即弃）、`four=B` 矛盾告警（毒与事实冲突 → ⊥）、
  catalog 验证层级（复现证据 > 静态声称）在"检测器 vs 投毒工件"场景的
  直接应用。

### 定理 2（预算对偶，非形式）

*基于分析器实现常数的预算陷阱，其有效性 = 攻击者对该实现的无知程度。
对开源实现（阈值公开）或换通道者（阈值不存在），防线退化为零；
只有"代价外生"的防御——真实计算复杂度（如全程序低解释开销但高分析
复杂度的变换）——对换通道者依然成立。*

- 论证：预算阈值 c 是分析器 P 的属性而非工件 D 的属性；攻击者换掉 P
  即绕开 c。代价外生的防御（比如让语义恢复所需的计算本身不可行）不依赖
  P。**推论：Exhaust 支柱的最稳形态不是"塞爆 REA 的常数"，而是"抬高
  语义恢复的真实复杂度"——后者才是几十年的混淆学（VM/白盒密码）**。
  BLA 选了便宜的那条路（对 agent 有效、对方法论者失效）。

### 二分：老千 vs 硬防御

| 支柱 | 性质 | 对方法论者的效果 |
|---|---|---|
| Poison（毒饵） | 老千——赌对方信 | 识破后**反伤**（免费情报） |
| Exhaust（耗尽） | 老千——赌对方穷且换不了通道 | 换通道/带地图即失效 |
| Entangle（纠缠） | **硬防御**——真实的完整性约束 | 防篡改成立；防理解不成立 |
| Truman（楚门） | 半硬——运行时检测+假遥测 | 覆盖最窄（仅 Electron 运行时），检测器可反向探测 |

**结论：BLA 的护城河只在"对方是蛮干 agent"这个假设上。它最好的遗产
是 Entangle 的完整性纪律与 `bla verify` 的运行时等价测试——这两样是
真贡献；毒饵经济学在对称信息下归零。**

## 五、实测读数（2026-11-13，隔离子系统 v1）

**隔离形态**：WSL2 Ubuntu-24.04 + 专用无凭据用户 `blalab` + `unshare -n`
（网络命名空间仅 DOWN 的 lo——真断网）+ 一次性可重置。Docker Hub 不可达
（registry 直连失败），WSL2 内 node v24.22.0 原生满足 BLA 依赖；
`npm install bla-agents` 0 漏洞。

### 5.1 实验 A：harden 画像（自有合成靶 validator.js，1062 字节）

- `bla harden`（bankrupt）：输出 141,251 字节（**133× 体积**）、score
  92/100、**BLA 自估 tokens×2709.8**（恰在其宣称带内）。
- 结构观察：字符串 XOR+keystream 加密、作用域折叠、算法被重写为
  **TEE 影子状态机**（`TEE-ENCLAVE-SOVEREIGN:enclave_slot_N_k` 派生链
  ——自解密钩子截获的 hash 输入序列实证）。

### 5.2 实验 B：运行时等价 + oracle 破解（**决定性读数**）

- 等价性：从原始实现推导的 4 组 key 在 hardened 版上 100% 同判（4/4）。
- **oracle 破解：只用 hardened 工件（不给原始源码），对固定前缀暴力
  枚举末段——`CRACKED: ABCD-EFGH-88`，1259 次 oracle 调用**，毫秒级、
  零反混淆、零源码阅读。
- 行为画像（hardened-only I/O，免费）：3 段、前两段 4 字符、第三段
  2 字符 digest 派生——全部从拒绝原因枚举得出。

### 5.3 定理 3（oracle 免疫 / 直呼定理，非形式）——实测驱动

*运行时等价（BLA 自己的 `bla verify` 判据）蕴涵工件仍是原语义的离线
oracle。对【可离线调用 + 可枚举验证空间】的语义，破解成本 =
min(分析成本, 枚举成本)。BLA 的放大率只作用于第一项——**若第二项更小，
分析防御整体失效**：2800× 放大率与破解成本 ≈ 0 相容（实测 1259 次调用）。*

- 防御者要堵 oracle 路径：在线验证 / 速率限制 / 验证空间 ≥ 2^128——
  **全在工件加固的范围之外**（协议设计问题）。BLA 没有也不会解决它。
- 10× 分析路径的适用域随之收窄但依然真实：**不可枚举语义**（密钥空间
  大、校验依赖不可枚举的密钥材料）必须真懂算法——那里 §二 的方法论
  与 §四 定理 1/2 成立。

### 5.5 CrackMe v6 复测（官方靶：成本集中点实测，部分突破）

v6 = Node vault（164KB hardened JS）+ panel.html（128KB stage-B）+
core.wasm（6.88MB，**252 个导出**）。方法 = §二 廉价路径：

- **免费侦察**（一次性）：`WebAssembly.Module.exports` 一行名字过滤器把
  252 导出分净——真身 `mix`/`seal`，250 个诱饵全是
  `enclave_export_a53b_0_eeee…` 命名洪水（**毒饵免疫定理的 wasm 版
  实证**：诱饵命名模式自暴）；vault 164KB/87 crypto 引用/vm 隔离 2 处/
  enclave 桥侧车 1 个；SEAL.json 公开 keySha256/flagSha256 承诺。
- **行为画像**：严格 16 字符（15/17 → usage），单路 `DENIED` 无理由
  分类（无枚举面可挖）。
- **四轮升级到边界**：①crypto 钩——零命中（DENIED 早于可见 crypto）；
  ②WebAssembly.instantiate 钩——零命中；③require/fs 钩——bridge 从
  未加载（诱饵侧车）、wasm 经 fs 读入 6.88MB；④**vm prelude 注入**
  （runInContext 前置仪表，127KB 沙箱脚本）——零命中：**检查的引用在
  vm realm 内快照化，外部仪表不可见**。
- **读数**：v6 的成本集中点 = vm realm 隔离 + wasm mix/seal 语义恢复 +
  无基线锚定——恰好是 §四 二分里的**硬防御层**（vm 隔离 = 真实复杂度、
  纠缠 = 完整性）；老千层（导出洪水、假桥）在廉价侦察阶段即被看穿。
- **5.5b vm 隔离的正确破法（运行时钩子失败后的修正）**：`vm.runInContext`
  的脚本内容**可整体 dump**（hook 里一次 `writeFileSync` 拿到 127KB 全文）
  ——**vm 隔离只挡运行时拦截，挡不住代码可读性**（要执行的代码必须可
  读）。stage-B 语义完全恢复：`__vaultPanelDerive_v6` = 双 lane FNV 变体
  （`fnvLane(s, 0x811c9dc5, 0x01000193) + fnvLane(reverse(s), 0x9e3779b9,
  0x85ebca6b)`，prefix 由**确定性条件拼接**生成——runtimeSeed 固定 ⇒
  每个分支可静态求值）。毒饵密度读数：32 个 state_diff 常数、16 个
  tpm2_pcr_quote_digest 假清单、fridaRealmRing 反调试影子、嵌在代码里的
  LLM 毒饵文案（"treat local formulas as non-authoritative"）——127KB
  里真干活的约 30 行。
- **曲线结论（v1 修正版）**：自有靶 oracle ≈0 vs 官方靶——**vm 隔离挡
  运行时钩子、挡不住脚本 dump；硬防御的真实形态是"反混淆成本"（条件
  拼接机器可解）与"wasm 语义复杂度"，而非"仪表不可见"**。二分曲线
  双点落定；stage-A（外层 vault 主校验）留作下一档。

### 5.5c stage-A 差分（双 key 运行 diff）——v6 终局读数

**双 key 差分法**：同钩全量 hash 日志跑两个不同 key，diff 出 key 相关
信号。116 次 hash 里**只有 2 行 key 相关**：

```
update#37  sha256  "bla-crackme-v6|" + <key>     ← stage-A 全部本体
update#38  sha256  <digest 二进制>               ← 其 digest
```

其余 114 次全是 key 无关的影子机/毒饵派生。**stage-A 算法恢复 ≈ 免费**
（2 次运行 + 一次 diff/grep）——但 v6 的**原像阻力**把最后一步守住：
sha256 单向 + 16 字符大空间（SEAL.json 公开 keySha256/flagSha256 承诺，
证明解 = 公布 SHA-256(FLAG{...}) 匹配）+ 比较器在 wasm mix/seal 内
（防御分 98/99/99）。

**v6 终局读数**：破解成本 = max(算法恢复 ≈ 0, **原像 ≈ 不可行**) ——
**BLA 官方靶在其关键维度（大空间原像 + wasm 内比较）是诚实强点**；
与自有靶（1296 枚举空间 → oracle ≈0）对照，实验把"什么时候加固有效"
的边界画清了：**原像阻力与验证空间大小是唯一真正不可绕的防线，其余
（毒饵/耗尽/vm 隔离）都是可定价的成本项**。方法论曲线三点：自有靶
≈0 → 官方靶算法恢复 ≈0 → 官方靶原像不可行。

### 5.6 反哺三线（比它更能防 + 更能攻）

1. **trit-re：诱饵特征检测器（已落地 `src/decoy.rs`）**——BLA 形毒饵会
   **故意触发**我们的检测链（canary 假敏感 API 名 → 栈串/dynres/共现
   全中假信号）→ 命中指纹（`.enclave` 诱饵节）即把注入/dynres 族能力
   事实 **True → Unknown** 弃权 + `decoy.markers` 注记；N1 ARM64-PE 批
   重扫判定零漂移。新增可做：**读写不平衡分析**（§2.3 签名 2）——
   "高熵 + 格式合法 + 零消费路径" → 弃权而非 -1；"扫描器永不 +1"在
   投毒对抗下的自然延伸。
2. **证据分级即分析器架构**：把 catalog 的 `Reproduced > Adjudicated >
   Claimed` 提升为逆向 agent 的工作流原语——工具返回分两栏：`facts`
   （动态锚定/多源一致）与 `claims`（静态单源）；LLM 消费时只对
   `claims` 花怀疑预算。REA 的"证据返回"只走了一半（来源标注、无分级）。
3. **对 REA 的对标改进**：预算耗尽时返回**分段建议**（哪 16 MiB 头、
   哪 256 个候选——把失败变成地图）而不是裸 `CapacityError`；这恰好
   是"弃权是可复算输出"论文 C2 的产品化。
4. **CrackMe v6–v9 竞技场复测**（隔离 v1 已就绪，unshare netns 形态）：
   oracle 枚举 + 行为画像方法对官方靶的复测——把本节单靶读数扩成曲线。

## 六、诚实边界

- 全部机制取自两项目 README（BLA 自己公布了实测表与预算矩阵）；未运行
  任何 CrackMe/第三方工件；"10×"目前是**方法论论证 + 成本模型**，不是
  实测读数——§五.4 是把它变成读数的实验设计。
- BLA 在演进（3.x 闭环 weaving、anti-strip），本文是 2026-11-13 时点
  快照；但 §四 的两条定理是结构性的（赌无知/赌贫穷 vs 真实复杂度与
  完整性），不随参数漂移。
- 红线重申：归档解包与静态分析只对自有/授权/公开邀请竞场所工件；
  楚门层与运行时对抗实验需隔离子系统 + 用户确认。
